# Changelog

## 0.1.0

First public release.

- Installable `papercourt` skill with a focused empirical-ML review workflow.
- Decimal arithmetic checks for values, differences, relative changes, ratios,
  and unweighted means, with explicit comparison controls.
- Exact-quote checks, CSV line locations, JSON record pointers, input hashes,
  and byte-preserved report replay.
- Markdown, standalone HTML, and structured JSON reports that distinguish
  script checks from model assessments and retain unknown outcomes.
- Original MIT-licensed example with supported, conflicting, confounded,
  overgeneralized, and missing-evidence claims.
- Project installer, repository checks, cross-platform CI, and reproducible
  source and standalone skill release bundles.

This release does not establish review-quality improvements or support arbitrary
PDF extraction, automatic experiments, or final academic judgments.
